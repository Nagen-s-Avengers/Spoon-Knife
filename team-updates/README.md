# Team Publish Notes
Each team publishes here, on their own branch, using their team's 
feature name (matching your branch name):
- team-updates/[your-feature]-intent.md  — written before you build 
  (your planned design)
- team-updates/[your-feature].md          — written after you build 
  (what actually happened)
Example for the Appointments team: team-updates/appointments-intent.md, 
then team-updates/appointments.md.
Other teams will read these files directly from your branch — during 
this week's round-robin validation, and again in Week 3.
